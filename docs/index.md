## Introduction

SDKs, tools, and apps for the mobile game TinyTower by Nimblebit.

## Monorepo Structure

The Tinyburg monorepo is organized into multiple packages and apps. Below is an overview of the packages included:

| Package | Description | Links |
| ------------------------- | ------------------------------------------------------------------------------ | ---------- |
| `@tinyburg/bitprints`     | Blueprints for constructing a tower in TinyTower using finite state machines    | [README]() |
| `@tinyburg/doorman`       | Your friendly TinyTower doorman: elevator rides, restocking, building, and more | [README]() |
| `@tinyburg/insight`       | Provides information into and about TinyTower using frida                       | [README]() |
| `@tinyburg/nimblebit-sdk` | General purpose SDK for connecting to Nimblebit's cloud services                | [README]() |
| `@tinyburg/tinytower-sdk` | Api for the mobile game TinyTower by Nimblebit                                  | [README]() |
| `@tinyburg/trading-sdk`   | Trading sdk for tinyburg.app                                                    | [README]() |
