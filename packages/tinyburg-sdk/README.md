# @tinyburg/tinyburg-sdk

The tinyburg.app api spec for the game endpoints under `/v1/<game>`: link a
player's game accounts and, with their consent, act on their saves, snapshots,
raffles, gifts and friends. Implemented by `apps/tinyburg.app`, and called by
its client, authproxy, social-circles and the treasury. Trades live in
`@tinyburg/treasury-sdk`.

Formerly `@tinyburg/trading-sdk`.
