# Tinyburg

Everything I know about the mobile game TinyTower by Nimblebit.

## Structure

- [apps/archivist](apps/archivist) - downloads and archives every version of
  Nimblebit games directly from the Google Play Store.
- [apps/auto-gold-bits](apps/auto-gold-bits) - send a bitizen to this tower and
  it will come back to you with max stats and with the dream job if you are
  requesting bitizens for a certain floor.
- [apps/doorman-clone](apps/doorman-clone) - visit this tower and you will get
  your doorman sent back to you as a bitizen.
